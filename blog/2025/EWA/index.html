An introduction to Exponentially Weighted Moving Averages

Created on December 10, 2025

2025   ·   Fundamentals   ·   Fundamentals

Introduction

Exponentially Weighted Averages (EWA) are a method used to calculate moving averages where more recent data points are given higher weights, while older data points receive lower weights that decay exponentially.

The purpose of this post is to introduce unnormalized and normalized Exponentially weighted moving average(EWMA)/Exponential Moving Averages(EMA).

In (almost) all practical contexts, EWMA and EMA are synonymous and can be used interchangeably.

Classification

EWMA can be classified into two categories

  • Normalized EWMA
  • Unnormalized EWMA (Unnormalized Decaying Sum/Decaying Sum Accumulator)

Conceptual notes

Unnormalized EWMA (Unnormalized Decaying Sum/Decaying Sum Accumulator)

From the Momentum equation:

\[\hat{g_t} = \beta^0 g_t + \beta g_{t-1} + \beta^2 g_{t-2} + \beta^3 g_{t-3} + \beta^4 g_{t-4} + ... + \beta^t g_0\]

OR

\[\hat{g_t} = \sum_{\tau = 0}^t \beta^{t-\tau} g_\tau\]

Now typically $\beta = 0.9$ for momentum based gradient descent.

$\beta$ Value Effect on g_t
$\beta^0$ 1 Most effect
$\beta^1$ 0.9 lesser effect
$\beta^2$ 0.81 even lesser effect
$\beta^3$ 0.73 even lesser effect
$\beta^4$ 0.65 even lesser effect
$\dots$ $\dots$ $\dots$
$\beta^t$ $\approx 0$ almost no effect

There is a decaying effect of the past gradients and hence it does not blow up to infinity because $\beta < 1$. If $\beta \geq 1$ then all velocities will add up and blow up to infinity.

Normalized EWMA

Normalized EWMA takes the form:

\[\hat{g_t} = \beta^0 (1-\beta) g_t + \beta (1-\beta) g_{t-1} + \beta^2 (1-\beta) g_{t-2} + \beta^3 (1-\beta) g_{t-3} + \beta^4 (1-\beta) g_{t-4} + ... + \beta^t (1-\beta) g_0\]

OR

\[\hat{g_t} = (1-\beta)\sum_{\tau = 0}^t \beta^{t-\tau} g_\tau\]

In simpler words, It scales everything by $1-\beta$.

Why is this needed?

Mathematical intuition

The normalization by $1-\beta$ ensures that the weights sum to approximately 1, making the EWMA a proper weighted sum instead of decaying sum.

\[(1-\beta)( 1 + \beta + \beta^2 +\beta^3 + \dots + \beta^t )= (1-\beta)\frac{1-\beta^{t-1}}{1-\beta}\] \[(1-\beta)\sum_{\tau = 0}^t \beta^\tau = (1-\beta)\frac{1-\beta^{t-1}}{1-\beta}\]

If t is extremely large with $\beta < 0.9$, $\beta^{t-1} \approx 0$

\[(1-\beta)\sum_{\tau = 0}^t \beta^\tau = (1-\beta)\frac{1-}{1-\beta}\] \[(1-\beta)\sum_{\tau = 0}^t \beta^\tau = 1\]

In the normalized EWMA case, say $g_t$ is constant i.e. all gradients are equal to a constant value, the Normalized EWMA will converge to $g_t$ while the unnormalized EWMA will converge to $\frac{g_t}{1-\beta}$, and with $\beta < 1$, the unnormalized EWMA will scale up to larger values (up to 10x with $\beta=0.9$).

Conceptual understanding

The key difference between normalized and unnormalized EWMA lies in what they’re designed to estimate.

Unnormalized EWMA is essentially a momentum accumulator. It deliberately scales up the average by a factor of $\frac{1}{1-\beta}$. With $\beta = 0.9$, this means a 10x amplification. If you’re averaging gradients that are consistently around 0.1, the unnormalized EWMA will settle around 1.0. This “amplification” is actually desirable in optimization contexts because it builds up momentum—the algorithm moves faster in consistent directions.

Normalized EWMA, on the other hand, is a true average. By multiplying by $(1-\beta)$, we cancel out the $\frac{1}{1-\beta}$ amplification factor, ensuring the weights sum to 1. If your gradients are consistently 0.1, the normalized EWMA stays around 0.1. This preserves the original scale of your data, making it ideal for forecasting, smoothing, and any application where you want an unbiased estimate.

Simpler analogy: If you want a rolling sum of gradients, use unnormalized EWMA, if you need an approximate expectation/average over the gradients of the loss curvature, use normalized EWMA.

In practice:

  • Unnormalized EWMA → Use in optimization (momentum) where you want accumulation
  • Normalized EWMA → Use in Adam, RMSProp where you want scale preservation of gradients.
